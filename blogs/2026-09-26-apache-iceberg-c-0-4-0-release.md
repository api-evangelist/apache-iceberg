The Apache Iceberg community is pleased to announce the 0.4.0 release of Apache Iceberg C++ . This release includes over 160 pull requests from 26 contributors, including 12 first-time contributors. iceberg-cpp is a native C++ implementation of the Apache Iceberg table format, providing libraries for reading, writing, and managing Iceberg tables in C++ applications.
