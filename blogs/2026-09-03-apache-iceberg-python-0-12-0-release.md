The Apache Iceberg community is pleased to announce the 0.12.0 release of Apache Iceberg Python . The 0.12.0 release covers development work from early February through late August 2026 and is the result of merging over 470 pull requests from 58 contributors, including more than 40 first-time contributors. These notes cover the highlights.
